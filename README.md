# E-Commerce-Grocery-Store-Website
A project which demonstrates my abilities of making a server-side based project.
I used Flask, Flask-WTF-Forms, Jinja and other languages to code up this project.

To run this project:
• Place HTML files in a folder called template.
• Place image files (.jpg, .ico) in a folder called static.
• Place .css files in the static folder too.
• In the run the command  "app.py python -m flask run" to startup the website.
• Make sure to place all files and folders in the same directory.
